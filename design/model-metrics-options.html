Right now the exact figures (≈3.4% word error, ≈7.6× realtime) hide in a strip that only opens on hover — so the bars float without any number to anchor them. Below, four treatments that keep the number permanently on screen next to its bar. Same four real models, real accent, real column layout so you can judge how each one stacks down a list. Bars stay neutral on purpose — colour is reserved for state (in-use), not decoration.
